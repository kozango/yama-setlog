# 山せとろぐ（仮）

GPXと写真・動画を読み込み、撮影時刻と位置からルートへ自動で紐づけて山行ムービーを作るUIプロトタイプです。

## 現在できること

- GPXファイルと写真・動画の選択
- 対象動画の個別チェック・一括選択・プレビュー対象確認
- 選択したローカル動画・写真の実データプレビューと前後移動
- 完成動画の長さと縦横比の変更
- GPX表示（白線ルート・現在地・標高断面）の切り替え
- 地名ラベル密度（なし・主要地点・詳細）の切り替え
- 地図・地点時刻・標高の表示切り替え
- 前穂・奥穂の実GPX形状を使った完成イメージ表示
- 有限の処理ステップと完了状態が分かる構成プレビュー生成

現時点では編集体験を検証するフロントエンドプロトタイプです。動画解析と実際の動画書き出しは未実装です。

