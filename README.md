# 山せとろぐ（仮）

GPXと写真・動画を読み込み、撮影時刻を照合して山行ムービーを作る、スマートフォン向けのUIプロトタイプです。

## 現在できること

- GPXファイルと写真・動画のまとめて選択
- 撮影時刻による素材の自動並べ替えとGPX時刻との照合
- 対象素材の個別チェック・一括選択・個別プレビュー
- 完成尺どおりの素材順を確認できる連続プレビュー
- 30秒・60秒・90秒と、縦・横・正方形の選択
- 完成動画には実際の撮影日・時刻と、実GPX軌跡上の撮影時点を表示
- ルート地図はデフォルトで表示し、不要な場合はOFFに変更可能
- `trkpt`内の地点名を読み取り、地名表示を「なし・主要地点・詳細」から選択可能
- YAMAPなどのルートGPXへ、山レコなど別GPXの地名を座標で自動合成
- 撮影日時と最寄り地名の表示を個別にON/OFF可能
- ルート地図を左上・右上・左下・右下へ配置可能
- 各素材へ任意のキャプションを追加し、プレビューと完成動画へ反映
- キャプション位置を上・中央・下から選択可能
- 端末内での書き出し進捗、完成動画の再生とダウンロード
- 「素材選択 → 確認 → 処理待ち → 保存」に絞ったスマートフォン向け画面

現時点では端末内でGPX解析・素材照合・プレビュー・動画書き出しを行うフロントエンドプロトタイプです。GPXの実軌跡と撮影時点は表示しますが、固定の地点名・標高・DAY表記や説明キャプションは完成動画へ表示しません。GPXの記録停止区間に撮影された素材は、その山行内の最寄り記録地点へ結びます。

## 起動

```bash
npm install
npm run dev
```
