# 山せとろぐ（仮）

GPXと写真・動画を読み込み、撮影時刻と位置からルートへ自動で紐づけて山行ムービーを作るUIプロトタイプです。

## 現在できること

- GPXファイルと写真・動画の選択
- 対象動画の個別チェック・一括選択・プレビュー対象確認
- 選択したローカル動画・写真の実データプレビューと前後移動
- 書き出し前に完成尺どおりの素材順を確認できる連続プレビュー
- 選択尺に合わせた端末内動画書き出しと完成ファイルのダウンロード
- 完成動画の長さと縦横比の変更
- GPX表示（白線ルート・現在地・標高断面）の切り替え
- ルートラベル（なし・開始終了・DAY時刻）の切り替え
- 地図・地点時刻・標高の表示切り替え
- 選択したGPXの実軌跡・撮影時刻・DAY・座標・標高を使った完成イメージ表示
- 撮影時刻による素材の自動並べ替えと、最寄りGPX地点への照合
- 有限の処理ステップと完了状態が分かる構成プレビュー生成

現時点では端末内でGPX解析・素材照合・プレビュー・動画書き出しを行うフロントエンドプロトタイプです。GPXに地点名が含まれない場合、地名は推測せず座標を表示します。

## 起動

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
